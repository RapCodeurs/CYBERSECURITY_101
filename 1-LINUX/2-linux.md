Tache 2 : Acceder a votre machine Linix a l'aide de SSH


SSH nous permet d'exécuter à distance des commandes sur un autre appareil.
Toutes les données envoyées entre les appareils sont cryptées lorsqu'elles sont envoyées sur un réseau tel qu'Internet

Utilisation SSH pour vous connecter à votre Linux Machine

La syntaxe à utiliser SSHest très simple. Il suffit de fournir deux choses :

1. L'adresse IP de la machine distante

2. Corriger les informations d'identification d'un compte valide avec lequel se connecter sur la machine distant

SSH < Nom machine >@<IP>
