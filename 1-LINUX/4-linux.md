Tache 4 : L'interaction avec le systeme de fichiers 

Dans cette tâche, nous allons apprendre quelques commandes supplémentaires pour interagir avec le système de fichiers afin de nous permettre de :

créer des fichiers et des dossiers
déplacer des fichiers et des dossiers
supprimer des fichiers et des dossiers


touch :	Créer un fichier
mkdir :	créer un répertoire	Créer un dossier
cp	: Copier un fichier ou un dossier
mv	: Déplacer un fichier ou un dossier
rm -R	: Supprimer un fichier ou un dossier
file : Déterminer le type d'un fichier

deplacer un fichier vers un autre dossier :àà
mv myfolder/file1 myfolder2/



Comment créeriez-vous le fichier nommé « newnote » ? : Ttouch newnote
Sur la machine déployable, quel est le type de fichier « unknown1 » dans le répertoire personnel de « tryhackme » ? ASCII text

Comment déplacerions-nous le fichier « myfile » vers le répertoire « myfolder » : mv myfile myfolder/
