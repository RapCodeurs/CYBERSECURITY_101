Tache 2 : Moteurs de recherche

"exact phrase": Les guillemets doubles indiquent que vous recherchez des pages avec le mot ou la phrase exacte. Par exemple, on pourrait rechercher "passive reconnaissance" pour obtenir des pages avec cette phrase exacte.

site:: Cet opérateur vous permet de spécifier le nom de domaine auquel vous souhaitez limiter votre recherche. Par exemple, nous pouvons rechercher des histoires de réussite sur TryHackMe en utilisant site:tryhackme.com success stories.

-: Le signe moins vous permet d'omettre les résultats de recherche qui contiennent un mot ou une phrase particulière. Par exemple, vous pourriez être intéressé à en savoir plus sur les pyramides, mais vous ne souhaitez pas consulter les sites Web touristiques ; une approche consiste à rechercher pyramids -tourism ou -tourism pyramids.

filetype:: Cet opérateur de recherche est indispensable pour trouver des fichiers plutôt que des pages Web. Certains des types de fichiers que vous pouvez rechercher à l'aide de Google sont Portable Document Format (PDF), Microsoft Word Document (DOC), Microsoft Excel Spreadsheet (XLS) et Microsoft PowerPoint Presentation (PPT). Par exemple, pour trouver des présentations sur la cybersécurité, essayez de rechercher filetype:ppt cyber security.

Comment limiteriez-vous votre recherche Google aux fichiers PDF contenant les termes rapport sur la cyberguerre? : filetype:pdf cyber warfare report
