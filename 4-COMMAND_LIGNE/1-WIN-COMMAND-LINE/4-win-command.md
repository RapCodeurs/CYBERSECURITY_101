Tache 4 : Gestion des fichiers et des disques

cd :  afficher le lecteur et le répertoire actuels
dir : consulter les répertoires enfants

Notez que vous pouvez utiliser les options suivantes avec dir:

    dir /a- Affiche également les fichiers cachés et système.
    dir /s- Affiche les fichiers dans le répertoire actuel et tous les sous-répertoires.

tree : pour représenter visuellement les répertoires et sous-répertoires enfants.

Vous pouvez passer à n'importe quel répertoire en utilisant la commande cd target_directory; cela équivaut à double-cliquer sur le target_directory sur votre bureau. De plus, vous pouvez utiliser cd .. monter d'un niveau. Un exemple est présenté dans la sortie du terminal ci-dessous.

mkdir directory_name
type : Vous pouvez facilement visualiser des fichiers texte avec la commande

dir C:\Treasure\Hunt

type C:\Treasure\Hunt\flag.txt
