Tache 2 : Informations de base du systeme

Avant d’émettre des commandes, nous devons noter que nous ne pouvons émettre les commandes que dans le chemin Windows. Vous pouvez émettre la commande SET pour vérifier votre chemin depuis la ligne de commande. La sortie du terminal ci-dessous montre le chemin où MS Windows exécutera les commandes, comme indiqué par la ligne commençant par PATH=.

SET :  pour vérifier votre chemin depuis la ligne de commande
VER : pour déterminer la version du système d'exploitation (OS)

Assez d'échauffement. Découvrons des informations plus approfondies sur le système. Nous pouvons exécuter le systeminfo commande permettant de répertorier diverses informations sur le système telles que les informations du système d'exploitation, les détails du système, le processeur et la mémoire. Le terminal ci-dessous affiche un extrait de la sortie affichée.

systeminfo : permettant de répertorier diverses informations sur le système 

help- Fournit des informations d'aide pour une commande spécifique
cls- Efface l'écran d'invite de commande.
