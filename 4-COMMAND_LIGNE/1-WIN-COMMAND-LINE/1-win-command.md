Tache 1 : Introduction

Le but de cette salle est de vous apprendre à utiliser MS Windows Command Prompt cmd.exe, l'interpréteur de ligne de commande par défaut dans l'environnement Windows. Nous allons apprendre à utiliser la ligne de commande pour :

    -Afficher les informations de base du système
    -Vérifier et dépanner la configuration du réseau
    -Gérer les fichiers et les dossiers
    -Vérifier les processus en cours d'exécution


L’utilisation d’un CLIoutre la rapidité et l'efficacité. Nous en citerons quelques-uns :

Utilisation réduite des ressources: Les CLI nécessitent moins de ressources système que les interfaces graphiques gourmandes en graphiques. En d'autres termes, vous pouvez exécuter votre CLIsystème sur matériel plus ancien ou systèmes avec mémoire limitée. Si vous utilisez le cloud computing, votre système nécessitera moins de ressources, ce qui réduira votre facture.
Automatisation: Alors que vous pouvez automatiser INTERFACE GRAPHIQUEtâches, créer un fichier batch ou un script avec les commandes que vous devez répéter est beaucoup plus simple.
Gestion à distance: CLIle rend très pratique à utiliser SSHpour gérer un système distant tel qu'un serveur, un routeur ou un IoTappareil. Cette approche fonctionne bien sur les vitesses de réseau lentes et les systèmes aux ressources limitées.

Quel est l’interpréteur de ligne de commande par défaut dans l’environnement Windows ? : cmd.exe
