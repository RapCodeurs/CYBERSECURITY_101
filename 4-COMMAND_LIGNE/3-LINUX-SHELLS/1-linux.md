Tache 1 : introduction 


Objectifs d'apprentissage

    Apprendre l'interaction avec Linuxcoquille
    Utilisez les commandes shell de base
    Explorez les types de Linuxcoquilles disponibles
    Écrivez quelques scripts shell


Pour voir quel shell vous utilisez, tapez la commande suivante : echo $SHELL
lister les shells disponibles dans votre Linux OS : cat /etc/shells
vous pouvez saisir le nom du shell présent sur votre système d'exploitation : zsh


Quel shell est livré avec la coloration syntaxique comme fonctionnalité prête à l'emploi ? : fish
Quel shell n'a pas de correction orthographique automatique ? : bash
Quelle commande affiche toutes les commandes précédemment exécutées de la session en cours ? : history

Quel est le shebang utilisé dans un script Bash ? : #!/bin/bash
Quelle commande donne des autorisations exécutables à un script ? : chmod +x
Quelle fonctionnalité de script nous aide à configurer des tâches itératives ? loops
