Tache 6 : Invite de commande

Nous continuons avec les outils disponibles via le Configuration du système panneau.

L'invite de commande (cmd) peut sembler intimidant au début, mais ce n'est vraiment pas si mal une fois que vous comprenez comment interagir avec lui. 

Dans les premiers systèmes d’exploitation, la ligne de commande était le seul moyen d’interagir avec le système d’exploitation.

Lorsque l'interface utilisateur graphique (GUI) a été introduite, elle permettait aux utilisateurs d'effectuer des tâches complexes en quelques clics sur un bouton au lieu de saisir des commandes dans l'invite de commande. 

Même si l'interface graphique est le principal moyen d'interagir avec le système d'exploitation, un utilisateur d'ordinateur peut toujours interagir via l'invite de commande. 

Dans cette tâche, nous ne couvrirons que quelques commandes qu'un utilisateur d'ordinateur peut exécuter dans l'invite de commande pour obtenir des informations sur le système informatique.

Commençons par quelques commandes simples, telles que hostname et whoami.

La commande nom d'hôte affichera le nom de l'ordinateur.

Ensuite, examinons quelques commandes utiles lors du dépannage.

Une commande souvent utilisée est ipconfig. Cette commande affichera les paramètres d'adresse réseau de l'ordinateur.

Chaque commande disposera d'un manuel d'aide pour expliquer la syntaxe attendue pour exécuter correctement la commande, ainsi que tous les paramètres supplémentaires qui peuvent être ajoutés à la commande pour étendre son exécution.

Une commande pour récupérer le manuel d'aide d'une commande est /?.

La commande suivante est netstat. Conformément au manuel d'aide, cette commande affichera les statistiques du protocole et les connexions réseau TCP/IP actuelles.

La structure nous dit le netstat la commande peut être exécutée seule ou avec des paramètres, tels que -a,  -b,  -e, etc. 

Lorsque l’un des paramètres est ajouté à la commande racine, netstat dans ce cas, la sortie change. Jouez avec quelques-uns pour voir par vous-même. 

Le net La commande est principalement utilisée pour gérer les ressources du réseau. Cette commande prend en charge les sous-commandes.

Si vous tapez filet sans sous-commande, la sortie affichera la syntaxe de la commande racine affichant quelques-unes des sous-commandes que vous pouvez utiliser.

Lien utile : https://ss64.com/nt/

Dans Configuration système, quelle est la commande complète pour la configuration du protocole Internet ? : C:\Windows\System32\cmd.exe /k %windir%\system32\ipconfig.exe

Pour la commande ipconfig, comment afficher des informations détaillées ? : ipconfig /all
