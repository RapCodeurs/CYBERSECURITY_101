Taches 3 : Modifier les parametres UAC ( Contrôle du compte utilisateur )

Ce curseur dispose de quatre niveaux de sécurité, chacun contrôlant la manière dont Windows vous alerte lorsque des applications ou des utilisateurs tentent d'apporter des modifications au niveau du système. Ils se répartissent en quatre catégories standards comme expliqué ci-dessous :

    - Prévenez toujours : C'est la plus haute sécurité. Windows vous avertit chaque fois qu'une application ou vous-même essayez d'apporter des modifications et que le bureau s'assombrit (Secure Desktop).

    - Notifier pour les applications: Windows notifie uniquement lorsque applications essayez d'apporter des modifications, mais pas lorsque vous modifiez les paramètres Windows. Cette option est activée par défaut.

    - Notifier sans atténuation : Identique à ci-dessus (Notifier pour les applications), mais cette fois l'écran ne s'assombrit pas. 

    - Ne jamais notifier: Les notifications sont désactivées. Windows ne vous avertira d'aucune modification apportée par vous ou par aucune application. 

Quelle est la commande pour ouvrir les paramètres de contrôle du compte utilisateur ? (La réponse est le nom du fichier .exe, pas le chemin complet) : useraccountcontrolsettings.exe
