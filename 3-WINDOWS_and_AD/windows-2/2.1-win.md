Taches 2 : Configuration du système

Le Configuration du système utilitaire (MSConfig) est destiné au dépannage avancé et son objectif principal est d'aider à diagnostiquer les problèmes de démarrage. 

Comme vous pouvez le constater, Microsoft conseille d'utiliser Gestionnaire des tâches (taskmgr) pour gérer (activer/désactiver) les éléments de démarrage. L'utilitaire de configuration du système est NON un programme de gestion de startups. 

Si vous ouvrez le Gestionnaire des tâches pour le document ci-joint VM, vous remarquerez qu'il n'affiche pas d'onglet Démarrage. Vous ne verrez rien non plus dans l'onglet Démarrage à l'intérieur du msconfig utilité, comme indiqué ci-dessus. Cela est dû au fait que la machine connectée est un serveur Windows et que les serveurs Windows gèrent les applications de démarrage différemment des systèmes clients Windows. Contrairement à Windows 10 ou 11, vous ne verrez pas de programmes de démarrage dans Task Manager ou dans l'onglet Démarrage de msconfig. Sur ces machines serveur Windows, le seul moyen fiable d’afficher les éléments de démarrage au niveau utilisateur est via le dossier de démarrage lui-même. Vous pouvez y accéder en appuyant sur Win + R, qui ouvre la boîte de dialogue Exécuter, en tapant shell:startup, puis appuyez sur Entrée. Cela affichera tous les programmes de démarrage sous forme de raccourcis ou d'exécutables configurés pour s'exécuter automatiquement la prochaine fois qu'un utilisateur se connecte. C'est ici que vous pouvez vérifier les applications configurées pour être lancées au démarrage. Windows vous offre également des paramètres de configuration supplémentaires, que vous pouvez utiliser pour contrôler le comportement des performances et la récupération du système. Pour accéder à cette option, vous pouvez rechercher View advanced system settings dans votre barre de recherche et ouvrez-la. Cela ouvrira un System Properties panneau comme indiqué ci-dessous

Windows utilise un fichier de page comme espace mémoire virtuel supplémentaire lorsque la RAM physique est pleine. Cela permet d'éviter les ralentissements ou les plantages d'applications lorsque le système manque de mémoire. Vous pouvez afficher ou modifier le fichier de page en accédant au Advanced option en haut et en cliquant Settings sous le Performance languette.
