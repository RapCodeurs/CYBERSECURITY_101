Taches 4 : Gestion informatique

Le Gestion informatique (compmgmt) L'utilité comporte trois sections principales : Outils système, Stockage, et Services et applications.

Outils système

Commençons par Planificateur de tâches. Selon Microsoft, avec Task Scheduler, nous pouvons créer et gérer des tâches courantes que notre ordinateur effectuera automatiquement aux moments que nous spécifions.

Une tâche peut exécuter une application, un script, etc., et les tâches peuvent être configurées pour s'exécuter à tout moment. Une tâche peut s'exécuter lors de la connexion ou lors de la déconnexion. Les tâches peuvent également être configurées pour s'exécuter selon un calendrier spécifique, par exemple toutes les cinq minutes.

Pour afficher les tâches planifiées présentes sur le système, cliquez sur Task Scheduler Library. Cela affichera toutes les tâches planifiées du système. Vous pouvez cliquer sur n'importe lequel d'entre eux pour voir leurs détails. La capture d'écran ci-dessous montre une tâche planifiée nommée SystemInfoDailyLog configuré pour fonctionner every day at 10:00 AM. Ici, vous verrez le programme ou la commande qui s'exécutera lorsque la tâche sera déclenchée.

Le suivant est Visionneuse d'événements.

Event Viewer nous permet de visualiser les événements survenus sur l'ordinateur. Ces enregistrements d’événements peuvent être considérés comme une piste d’audit pouvant être utilisée pour comprendre l’activité du système informatique. Ces informations sont souvent utilisées pour diagnostiquer des problèmes et étudier les actions exécutées sur le système. 

Event Viewer dispose de trois volets.
Le volet de gauche fournit une arborescence hiérarchique des fournisseurs de journaux d'événements. (comme indiqué dans l'image ci-dessus)
Le volet du milieu affichera un aperçu général et un résumé des événements spécifiques à un fournisseur sélectionné.
Le volet de droite est le volet des actions.
