Tache 4 : Informations sur le systeme

Qu'est-ce que le Informations sur le système (msinfo32) outil ?

Selon Microsoft, "Windows inclut un outil appelé Microsoft System Information (Msinfo32.exe).  Cet outil rassemble des informations sur votre ordinateur et affiche une vue complète de votre matériel, de vos composants système et de votre environnement logiciel, que vous pouvez utiliser pour diagnostiquer les problèmes informatiques."

Les informations dans Résumé du système est divisé en trois sections :

    - Ressources matérielles
    - Composants
    - Environnement logiciel


Le résumé du système affichera les spécifications techniques générales de l'ordinateur, telles que la marque et le modèle du processeur.

Sous Composants, vous pouvez voir des informations spécifiques sur les périphériques matériels installés sur l'ordinateur. Certaines sections n'affichent aucune information, mais certaines sections le font, comme Affichage et Entrée.


Dans le Environnement logiciel Dans la section T, vous pouvez voir des informations sur les logiciels intégrés au système d'exploitation et les logiciels que vous avez installés. D'autres détails sont également visibles dans cette section, tels que le Variables d'environnement et Connexions réseau. 

Une autre méthode pour afficher les variables d’environnement est Control Panel > System and Security > System > Advanced system settings > Environment Variables OU Settings > System > About > system info > Advanced system settings > Environment Variables.

Quelle est la commande pour ouvrir les informations système ? (La réponse est le nom du fichier .exe, pas le chemin complet) : msinfo32.exe

Qu'est-ce qui est répertorié sous Nom du système ? : THM-WINFUN2

Tache 5 : Moniteur de ressources

Qu'est-ce que Moniteur de ressources (resmon)?

Selon Microsoft, "Le moniteur de ressources affiche par processus et par agrégat Processeur, des informations sur l'utilisation de la mémoire, du disque et du réseau, en plus de fournir des détails sur les processus qui utilisent des handles de fichiers et des modules individuels. Le filtrage avancé permet aux utilisateurs d'isoler les données liées à un ou plusieurs processus (applications ou services), de démarrer, d'arrêter, de mettre en pause et de reprendre les services, et de fermer les applications qui ne répondent pas à partir de l'interface utilisateur. Il comprend également une fonctionnalité d'analyse de processus qui peut aider à identifier les processus bloqués et les conflits de verrouillage de fichiers afin que l'utilisateur puisse tenter de résoudre le conflit au lieu de fermer une application et de perdre potentiellement des données."

Comme certains des autres outils mentionnés dans cette salle, cet utilitaire s'adresse principalement aux utilisateurs avancés qui doivent effectuer un dépannage avancé sur le système informatique.

Dans l'onglet Aperçu, Resmon comporte quatre sections :

    - Processeur
    - Disque
    - Réseau
    - Mémoire

Quelle est la commande pour ouvrir Resource Monitor ? (La réponse est le nom du fichier .exe, pas le chemin complet) : resmon.exe
