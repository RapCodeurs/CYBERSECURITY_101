TACHES 2 : DESKTOP

Le bureau Windows, également appelé interface utilisateur graphique ou INTERFACE GRAPHIQUEen bref, c'est l'écran qui vous accueille une fois que vous vous connectez à une machine Windows 10.

Traditionnellement, vous devez d’abord passer l’écran de connexion. L'écran de connexion est l'endroit où vous devez saisir des informations d'identification de compte valides ; généralement, un nom d'utilisateur et un mot de passe d'un compte Windows préexistant sur ce système particulier ou dans l'environnement Active Directory (s'il s'agit d'une machine jointe à un domaine).

sur linux : Quelle commande utiliseriez-vous pour rechercher tous les fichiers avec l'extension « .log » dans le répertoire actuel et ses sous-répertoires ? : find . -name "*.log"
