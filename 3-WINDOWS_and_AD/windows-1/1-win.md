Taches 1 : EDITIONS WINDOWS


Le système d’exploitation Windows a une longue histoire remontant à 1985 et constitue actuellement le système d’exploitation dominant dans les réseaux domestiques et d’entreprise. Pour cette raison, Windows a toujours été la cible de pirates informatiques et d’auteurs de logiciels malveillants.

Windows XP était une version populaire de Windows et fonctionnait depuis longtemps. Microsoft a annoncé Windows Vista, qui était une refonte complète du système d'exploitation Windows. Il y a eu de nombreux problèmes avec Windows Vista. Il n’a pas été bien accueilli par les utilisateurs de Windows et a été rapidement supprimé.

Lorsque Microsoft a annoncé la date de fin de vie de Windows XP, de nombreux clients ont paniqué. Les entreprises, les hôpitaux, etc. ont brouillé et testé la prochaine version viable de Windows, qui était Windows 7, par rapport à de nombreux autres matériels et appareils. Les fournisseurs devaient travailler contre la montre pour garantir que leurs produits fonctionnaient avec Windows 7 pour leurs clients. S’ils ne le pouvaient pas, leurs clients devaient rompre leur accord et trouver un autre fournisseur qui mettait à niveau leurs produits pour qu’ils fonctionnent avec Windows 7. Ce fut un cauchemar pour beaucoup, et Microsoft en a pris note.

Windows 7, dès sa sortie peu de temps après, a été marqué d'une date de fin de support.  Windows 8.x est arrivé et est parti et sa durée de vie a été de courte durée, comme Vista.

Puis est arrivé Windows 10 suivi de Windows 11(ouvre dans un nouvel onglet), qui est la version actuelle du système d'exploitation Windows pour les ordinateurs de bureau.

Windows 11 est disponible en deux versions : Home et Pro. Vous pouvez lire la différence entre Home et Pro ici(ouvre dans un nouvel onglet).

Même si nous n'avons pas parlé de serveurs, la version actuelle du système d'exploitation Windows pour les serveurs est Windows Server 2025(ouvre dans un nouvel onglet).

De nombreux critiques aiment critiquer Microsoft, mais ils ont fait de grands progrès pour améliorer la convivialité et la sécurité à chaque nouvelle version de Windows.
