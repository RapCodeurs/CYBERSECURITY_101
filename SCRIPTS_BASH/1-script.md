Bash est un langage de script qui s'exécute dans le terminal sur la plupart Linuxdistributions, ainsi que MacOS. Les scripts Shell sont une séquence de commandes bash dans un fichier, combinées pour réaliser des tâches plus complexes qu'une simple ligne et sont particulièrement utiles lorsqu'il s'agit d'automatiser des tâches d'administration système telles que les sauvegardes.
